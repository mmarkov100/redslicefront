# Red Slice Project

**Red Slice** — это веб-приложение с функцией чата, созданное на Flutter. Приложение поддерживает интеграцию с Firebase для аутентификации пользователей и обеспечивает адаптивный пользовательский интерфейс для входа, регистрации и взаимодействия с чат-ботом.

## 🌟 Особенности

- **Регистрация и вход через Firebase Authentication**
- **Функциональность чата**:
    - Отправка и получение сообщений
    - Генерация сообщений с помощью стороннего сервиса
    - Поддержка веток сообщений
- **Адаптивный дизайн**:
    - Приложение оптимизировано для мобильных устройств, планшетов и ПК
- **Интеграция с Firebase Hosting** для деплоя веб-версии

## 🛠️ Технологии

- **Frontend**: Flutter
- **Backend**: Java Spring Boot (реализует API и обработку данных)
- **База данных**: PostgreSQL
- **Аутентификация**: Firebase Authentication
- **Хостинг**: Firebase Hosting
